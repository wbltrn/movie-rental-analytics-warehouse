# Data Directory

This folder contains all datasets used in the project.

## Exports
- `dim_category.csv` – category dimension extracted from Sakila
- `dim_customer_loyalty.json` – customer loyalty data loaded into MongoDB

## Streaming Input
- `fact_rental_payment_part1.json`
- `fact_rental_payment_part2.json`
- `fact_rental_payment_part3.json`

These JSON files simulate incoming transaction batches used in the Databricks Bronze layer.
